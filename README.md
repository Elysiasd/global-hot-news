# 整点电讯

Hourly wire bulletin of global hot news, in a telegraph style. Times are Asia/Shanghai (UTC+8).

- Live edition: https://elysiasd.github.io/global-hot-news/
- Archives: https://elysiasd.github.io/global-hot-news/editions/

This repository is a static publish of the dashboard. It is updated about once an hour when a new edition is built.
